# 山西 × 江西｜2026 双人旅行行程网页

**旅行日期：2026 年 11 月 27 日晚—12 月 6 日；2 人，从广西梧州出发，12 月 6 日必须返回梧州。**

路线：梧州 → 广州 → 太原（晋祠、正宗沾串）→ 平遥 → 景德镇 → 婺源石城 → 三清山 → 上饶 → 广州 → 梧州。

## 网页

- 网站源文件：仓库根目录 [index.html](./index.html)，无需 Node.js、服务端或构建。
- 已提交文件：`index.html`、`manifest.webmanifest`、`sw.js`、`assets/icon.svg`、`.nojekyll`。
- 启用 GitHub Pages 后访问：<https://lys20001205.github.io/shanxi-jiangxi-trip-2026/>
- 如果网站仍显示 404，表示仓库 GitHub Pages 尚未启用或尚未成功发布，**不代表网页没有上传**。

### 首次发布 GitHub Pages（仓库管理员操作一次）

打开 <https://github.com/lys20001205/shanxi-jiangxi-trip-2026/settings/pages> ，在 **Build and deployment** 中设定：

1. **Source** = `Deploy from a branch`。
2. **Branch** = `main`，文件夹 = `/(root)`。
3. 点击 **Save**。之后每次向 `main` 提交更改都会重新部署，无需重复设置。

## 功能

- 10 天行程日历、逐日时间安排、住宿建议及地图导航。
- 太原“小溅沾串”用餐计划、餐厅备选及核实提醒。
- 分类筛选行程；预算交互估算（两人约 ¥10,900—18,900，**不是实时订单报价**）。
- 交通/住宿/景区预订核对清单、私人备注（只保存在当前设备的浏览器中）。
- 一键导出日历、打印或另存为 PDF、添加到手机桌面及离线缓存。
- 使用原创 SVG 插画，不依赖外部图片或框架。

## 维护方法

直接编辑 `index.html` 内的 `TRIP`（每日行程）、`BUDGET`（费用）、`TASKS`（预订清单）即可。修改网页后建议同步更新 `sw.js` 的 `CACHE` 版本号，避免手机继续显示旧离线版本。

## 使用提醒

- 2026 年 11 月 30 日太原—景德镇直飞是航季计划，指定日期机票、价格及运行情况**未确认**，不可当作已出票。
- 路线、餐饮营业时间、动车班次、景区索道和市集安排均应在实际出行前复核。
- 网站及 GitHub 公共仓库对所有人可见，**不要在 Git 仓库记录身份证、手机号码、订单号**；网页备注默认只在本机浏览器存储，不会同步到 GitHub。
- 各地实际气象条件可能改变观赏效果与交通安排。
