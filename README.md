# 山西 / 江西｜2026 交互式旅行规划器 v3

公开网页：<https://lys20001205.github.io/shanxi-jiangxi-trip-2026/>

## 固定旅行条件

- 两人，2026-11-27 下班后从梧州出发，**2026-12-06 必须回到梧州**。
- **12-05 提前抵达广州**，不把长距离转场放在最后一天。
- 用户偏好自然景观。**只选江西时从广州坐高铁进入江西，不安排航班**；选山西古迹或太原沾串时，去程可从广州飞太原。
- **山西与江西之间，以及入程以后的中途路段，全部采用高铁、动车或汽车，不安排中途航班。**
- 景德镇不再是必去点；可选景点包括太原/大同及江西自然景观。

## 交互功能

1. 景点池目前 **14 处景点**，其中龟峰丹霞、龙虎山、婺源石城、三清山、北岳恒山和鄱阳湖吴城等可按自然类型筛选。**43 张实拍资料图**分景点显示；单击图片放大并查看 Wikimedia Commons 作者、许可和原图。
2. 勾选景点即触发浏览器端规则式重新排程；预置 **江西自然优先、山西＋江西、山西古迹＋自然** 三种选择，支持单独勾选太原沾串。
3. 排程固定覆盖 2026-11-27 至 12-06 的 10 天。以目的地片区、预计交通和游览时长分配日期；婺源石城占前晚＋次晨；三清山与龙虎山按整天游览；吴城候鸟湿地优先预留两天。
4. 已选过多时，**明确列出未排入的景点**，不悄悄插进同一天。重新计算路线、住宿地区、交通粗估时长、预算区间及对应预订待办。
5. 景点池可搜索、按省份/自然/已选筛选；日程可展开查看各日多图；图片支持大图查看与来源链接。
6. 选择、个人备注、待办勾选及预算滑块保存在当前设备浏览器的 `localStorage` 中。不会提交到 GitHub，也不会跨设备同步。支持打印/PDF、生成日历文件。

**重要限制**：这是浏览器本地运行的**规则式行程计算**，不接入高德路线规划、12306实时余票、航司实时库存、酒店或景区开放接口。因此交通时长和票价是粗估，不能直接用作购票或最终接驳保证；天气、索道停运、冬季交通封闭需出发前再次核对。系统不会订票、预约或付款。

## 仓库结构

- `index.html`：页面骨架及交互区域
- `style.css`：响应式样式
- `data.js`：基础行程、原有景点图册、餐饮和参考信息
- `planner_data.js`：扩展的自然景点及景点池属性（可直接新增景点）
- `app.js`：页面渲染、图册与备注、预算、导出
- `planner.js`：勾选处理、10天规则式排程与冲突提示
- `sw.js`：离线缓存和版本失效
- `manifest.webmanifest`、`assets/icon.svg`：手机站点信息和图标

编辑 `planner_data.js` 及 `planner.js` 可扩展景点和路线。调整 `index.html` 等文件后，请同步更新资源查询参数及 `sw.js` 的缓存版本号，避免手机旧缓存继续生效。

## 验收结果

- **32,768 组**景点与沾串选择组合均满足日期不越界、返程边界和未排入项目数量一致性。
- Chromium 桌面（1366 px）与手机（390 px）交互测试：14景点、43张图、预置路线、勾选、筛选、超期警告、图片弹窗、清空与恢复预置全部通过。
- 实拍照片来自 Wikimedia Commons，逐张提供作者及授权原图；**不会将其他地方照片冒充某一景点**。其中菊径目前仅1张确定授权的实拍，不重复同一张照片充数。
