# 山西 / 江西 · 2026 双人旅行计划

- **时间**：2026-11-27 晚至 2026-12-06；12-06 必须回到广西梧州。
- **人数**：2 人。
- **主线**：梧州 → 广州 → 太原 → 大同 → 太原 → 上饶 → 婺源石城 → 三清山 → 上饶 → 广州 → 梧州。
- **交通约束**：只有广州→太原的去程考虑飞机；山西、江西之间以及后续全程采用高铁、动车和汽车。
- **暂时删除**：景德镇、平遥。优先保留大同三项古迹、太原沾串、婺源与三清山。

## 文件

- `index.html` — 页面结构。
- `style.css` — 排版与移动端布局。
- `data.js` — 日程、景点、实拍图、餐饮、预算、核查清单数据。以后修改行程主要编辑这个文件。
- `app.js` — 行程渲染、筛选、照片大图、预算、备注及日历导出。
- `sw.js` — 离线缓存（只缓存同源网页文件，**Commons 外部图片不保证离线**）。
- `manifest.webmanifest` / `assets/icon.svg` — 手机桌面图标。
