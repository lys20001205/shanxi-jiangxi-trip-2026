## 当前偏好与边界

- 两人，2026年11月27日下班后离开梧州，12月6日**必须回梧州**。
- 默认**江西自然风景优先**，景点池保留15处可选项目。默认选择：**武功山、三清山、龟峰丹霞、龙虎山**；石城、菊径、山西人文景点仅为可选。
- 默认去程广州坐高铁到萍乡北，然后萍乡/武功山→上饶/三清山→弋阳/龟峰→鹰潭/龙虎山；12月5日返回广州，12月6日坐动车到梧州。
- 不安排中途航班。除非主动选择山西景点，整个行程走铁路和公路。
- **太原沾串只能顺路吃：即使勾选“顺路沾串”，但没有勾选山西景点，也不会为餐饮增加跨省/去程航班/住宿。**
- 有山西景点时可选“顺路沾串”；无山西则隐藏太原/大同餐厅卡片。
- 不强制前往景德镇、平遥、云冈石窟或古村落。
